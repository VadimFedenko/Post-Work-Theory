# Предварительное сопоставление новой статьи с базой

Источник: `статья.md`, прочитана полностью. Сопоставление с `статья.txt`,
`research/methodology.md`, текущими 890 записями и сохранёнными обоснованиями.
Это оценка масштаба, а не завершённая переклассификация. Исходная база,
координаты, изображения и результаты предыдущего исследования не изменены.

## Главное изменение

В прежней методике сохраняющийся труд часто служил достаточной причиной
оставить общество в нуле. Считались и обязательные назначения, и искусственные
рабочие места, и полезные добровольные занятия. Поэтому распределение благ вне
рынка труда могло сосуществовать с отметкой `zero_variant`.

В новой статье предпочтительное определение другое: труд перестаёт быть
основным способом распределения благ. Люди могут продолжать работать; важнее,
определяет ли их труд основной доступ к ресурсам или доступ определяется
членством, кастой, общим обеспечением, собственностью, рентой, патронажем либо
правилами автономной инфраструктуры. Низкая доля неработающих теперь сама по
себе не основание для нуля. Отсутствие гарантий тоже не основание: для этого
существуют уклады 2, 4 и 6.

В статье есть существенная неоднозначность: «труд больше не является основным
способом распределения» и «есть альтернативный способ распределения» — разные
критерии. Второй захватывает и обычную зарплатную экономику с пенсиями или
небольшим сектором рентного дохода. Ниже принят первый критерий: альтернативный
механизм должен определять основной материальный доступ выбранной популяции,
а связь с автоматизацией/её ограничением сохраняется. По смешанным случаям
нужен best guess с обоснованием, без нового требования точной статистики.

## Нумерация: отдельная техническая операция

| Уклад | Старая статья и база | Новая статья |
|---|---|---|
| 1 | Концентрация + гарантии | Элиты + гарантии |
| 2 | Распределённый контроль + гарантии | Элиты без гарантий |
| 3 | Концентрация без гарантий | Обобществление + гарантии |
| 4 | Распределённый контроль без гарантий | Обобществление/личные активы без гарантий |
| 5 | Автономный ИИ + гарантии | Автономный ИИ + гарантии |
| 6 | Автономный ИИ без гарантий | Автономный ИИ без гарантий |

Старая 2 становится новой 3; старая 3 — новой 2. Сейчас таких ненулевых
записей **164**: 119 и 45 соответственно. Их переименование не означает
изменения содержательной оценки. Перенумерация затронет также альтернативы,
аналоги, документацию и генераторы.

Если выполнить только перенумерацию, распределение будет:
`0:486; 1:112; 2:45; 3:119; 4:12; 5:85; 6:31`.

Внутри описания нового уклада 3 осталась ссылка на промежуточное положение
UBC «между категориями 1 и 2». Если имеется в виду разделение контроля при
сохранённых гарантиях, по новой нумерации это между 1 и 3.

## Предварительный масштаб содержательных переносов

Сейчас: **404** посттрудовых/переходных и **486** нулевых записей.
Просмотрены список всех нулевых записей, их оценки и аналоги; у выбранных
кандидатов дополнительно сопоставлены описания и основания. Полного нового
решения для каждой из 486 записей пока нет.

Рабочий ориентир: **около 80–150 из 486** могут выйти из нуля при критерии
основного способа распределения. Это оценка низкой уверенности для планирования,
а не результат автоматического фильтра или измеренный интервал. Вероятный
масштаб первых относительно ясных решений — несколько десятков; остальное
составляют смешанные экономики, статусное обеспечение и технические сообщества.

При таком ориентире получится примерно **484–554 ненулевых** и **336–406
нулевых** записей; общее число останется 890. Встречные переносы из нынешних
404, уточнение охвата и отдельные ошибки этой прикидкой не посчитаны.

Низкие гарантии не мешают переносу. Для справки: среди нулевых только 49 имеют
центральную оценку гарантий не выше -0.15, ещё 67 — от -0.15 до +0.2. Использовать
этот показатель как автоматический фильтр нельзя: он не измеряет роль труда
в распределении. Общество без гарантий тоже может иметь нетрудовое распределение.

| Пример из существующей базы | Предварительное направление по новой статье | Основание и предел |
|---|---|---|
| Brave New World, оригинальный роман | 0 → 1 | Кастовое обеспечение, сохраняющиеся занятия не определяют принадлежность к нулю |

| The Midas Plague, обязательное потребление | 0 → 1 | Обязанность потреблять сосуществует с распределением автоматического изобилия |
| News from Nowhere | 0 → 3 | Общая собственность и доступ; выбранный ручной труд не равен зависимости благ от зарплаты |
| Andromeda Nebula, Земля Великого Кольца | 0 → 3 | Общее обеспечение при продолжающейся научной и другой полезной деятельности |

| Dune, Erewhon, племенные общества Horizon | Скорее сохранят 0 | Основное обеспечение продолжает требовать человеческого труда при запрете, утрате или недоступности соответствующей автоматизации |

## Сравнение новых укладов с прежними оценками

**1. Элиты + гарантии.** Сам смысл в основном совпадает. Главное изменение —
сюда попадают кастовое/статусное обеспечение и сохранённая обязательная работа,
если работа уже не основной распределитель благ. Раньше это слишком часто
отправлялось в ноль.

**2. Элиты без гарантий.** Это прежний 3. В новой статье особенно заметны
патронаж, клиентелы и дешёвое условное содержание без защищённого права.
Прежние нулевые решения иногда чрезмерно требовали и отсутствия труда,
и независимого обеспечения, хотя отсутствие надёжного обеспечения как раз
может быть причиной размещения здесь. Частично это уточнение статьи,
частично — непоследовательность прежнего применения критериев.

**3. Обобществление + гарантии.** Это прежний 2. Я учитывал полезную науку,
ремонт, заботу и творчество как работу. Для числовой оси участия это разумно,
но не должно было автоматически исключать общество с общей раздачей благ.
Так возникло расхождение между уже ненулевыми Миром Полудня/Star Trek и нулевой
Землёй Ефремова.

**4. Распределённые активы без гарантий.** Здесь описание содержательно
уточнилось сильнее: личные роботы, частные производящие активы, рыночный риск
и ресурсные ограничения. Раньше оценивался прежде всего фактический доступ
выбранных жителей. Например, ранняя Solaria стоит в старом 2 (новом 3), хотя
обеспечивается частными поместьями. Если отсутствие коллективной страховки
теперь само по себе означает «без гарантий», она кандидат на 4. Если надёжная
автономная самообеспеченность считается материальной гарантией, такой перенос
не следует автоматически. Полезно отдельно фиксировать форму собственности
и основание гарантии. Коллективная собственность с дефицитом и частная
собственность с общей страховкой тоже логически возможны.

**5–6. Автономный ИИ.** В целом соответствуют старым определениям. Важна
независимость производящей системы, а не обязательное прямое правление над
людьми. Корпоративное происхождение не означает сохранения власти живых
корпоративных владельцев. Поздний Axiom из WALL-E сейчас имеет основной 1,
альтернативу 5 и отрицательную координату контроля; статья однозначнее выбирает 5.

Отдельное расхождение: в статье Psycho-Pass иллюстрирует 5, а запись базы
учитывает живые человеческие мозги Sibyl и относит её к человеческой
технократической элите, то есть 1. Это различие определения контролирующего
субъекта, а не следствие нового определения посттрудового общества. Оно требует
явной оговорки, чтобы вся непрозрачная человеческая власть не становилась ИИ.

**Гарантии и охват.** Manna в статье переходит из 1 в 2 из-за стерилизации,
а база пока оставляет Terrafoam в 1, признавая поставку еды и жилья при
сильных оговорках. Учёт долгосрочного продолжения жизни может изменить саму
координату гарантий. Институт Fallout в статье относится к исключающему
режиму 2, а база оценивает привилегированных born-human жителей анклава и
получает 1, явно исключая работающих синтов. Это различие знаменателя:
сменить один номер без пересмотра охвата было бы некорректно.

**Адаптации.** Пример «Футурологического конгресса» в статье — книга Лема.
Существующая запись `congress-chemical-consumer-zero` описывает фильм The
Congress. Механически переносить аргументы из книги в её запись нельзя.
Ready Player One статья трактует через freemium-снабжение; запись базы
опирается на долговой труд IOI. Для переноса нужно обозначить эту разницу
интерпретаций, а не представить новое основание каноническим фактом.

**Доля неработающих.** Само новое определение не требует пересчитывать эту
ось. Низкая доля неработающих совместима с любым укладом 1–6. Добровольная
полезная деятельность остаётся работой для этой оси, но не основанием для нуля.

## Как добавить второй критерий

Техническая сложность небольшая; содержательная — один адресный проход по
нулевым случаям и проверка отмеченных ненулевых расхождений. Новый сбор лора
для всех 890 и повторение исследования с нуля не нужны. У **483 из 486**
нулевых записей уже есть `regime_analogy`: у 474 — один вариант, у 9 — несколько;
лишь у 3 аналога нет. Это заготовки направлений, а не доказательство переноса.

Рекомендуется добавить версионированный объект рядом с прежними результатами:

```json
{
  "classification_v2": {
    "definition": "labor_not_primary_allocator",
    "zero_variant": false,
    "allocation_basis": ["caste_entitlement"],
    "labor_allocation_relation": "secondary",
    "regime_primary": 1,
    "regime_alternatives": [],
    "confidence": "low",
    "reason": "Caste-based provision determines access despite retained work."
  }
}
```

Пример иллюстративный. Для смешанной экономики допустимо значение `mixed`
с best guess итогового признака и пояснением, без пропуска записи. Полезные
варианты основания: заработок, кастовый норматив, общая раздача, личные активы,
рента, патронаж, условное содержание, доступ к автономным системам.

Старые `record_type` и `regime_primary` сначала остаются исторической оценкой.
Нельзя сразу назвать старый флаг строгим критерием «никто не работает»:
старый корпус включает и частичные переходы, и исключения. Для настоящего
переключения между двумя формальными определениями старый критерий тоже
нужно нормализовать. Третье определение — экономическая нецелесообразность
человеческого труда — следует хранить отдельно; его нельзя надёжно вывести
из наличия ИИ или нынешней доли занятых.

После просмотра можно сделать новую классификацию основной, сохранив старую
версию. При этом потребуется обновить проверки, сводки, каталог, методику и
содержательную проверку завершённости. Изображения привязаны к устойчивым ID,
поэтому смена классификации сама по себе их не затрагивает.
