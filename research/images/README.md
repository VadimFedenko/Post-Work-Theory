# Изображения для 890 обществ — завершение 2026-10-17

Готовы **890 из 890 записей**, незавершённых нет. Подготовлены **671 комплект файлов**; после переиспользования одинаковых изображений это **628 различных исходников**. Один исходник сгенерирован, остальные получены из интернета. Все десять контактных листов просмотрены ассистентом; последние пятнадцать исправлений дополнительно просмотрены вместе с иконками. Это редакционная проверка, а не независимое рецензирование.

## Где лежат результаты

- `assets/images/<image_id>/original.*` — полученные байты изображения без перекодирования. Для некоторых источников это доступная веб-миниатюра, а не издательский мастер высокого разрешения. Фактические URL, размеры, объём и SHA-256 сохранены.
- `poster-320.webp` — портретная обложка **320 × 480 px**. Изображение вписано целиком с сохранением пропорций; у широких кадров остаются поля.
- `icon-32.png` — квадратная иконка **32 × 32 px** для круглой маски. `icon-circle-preview.png` показывает результат маски. Координаты квадратного кадрирования записаны в `assets.crop.icon`.
- [societies.json](../../data/societies.json) — заполненные `assets` каждой записи; пути относительно корня проекта.
- [society-assets.json](../../data/society-assets.json) — постоянная накладка для повторной сборки после исторических исследовательских ревизий.
- [manifest.json](manifest.json) — выбор изображения, источники, предыдущие варианты, локальные файлы и проверка по каждой группе.
- [progress.json](progress.json), [progress.md](progress.md), [events.jsonl](events.jsonl) — состояние и последовательный журнал операций, включая неудачные запросы.
- [contact-sheets/index.json](contact-sheets/index.json) — указатель десяти контактных листов; [final-corrections.jpg](contact-sheets/final-corrections.jpg) — последние исправленные обложки и иконки.

2013 основных файлов (исходник, обложка, иконка для каждой группы) занимают около **149 MiB**. Круглые превью, контактные листы, кэш поиска и сохранённые предыдущие материалы учитываются отдельно.

## Источники и пакетный сбор

Для книг полезным массовым источником оказались [Open Library Covers](https://openlibrary.org/dev/docs/api/covers) и архивы обложек Open Library: **204 группы** подготовлены через архивный способ получения. Другие крупные источники — Wikipedia/Wikimedia (**228 групп**, включая доступные отображаемые миниатюры), [TVmaze](https://www.tvmaze.com/api) (**98**), Steam (**62**) и Kitsu (**24**). Остальные изображения получены у издателей, авторов, в каталогах книг, журнальных архивах и на страницах самих произведений. Небольшие отдельные подборки закрывают пробелы этих источников.

Сохранены прямой URL фактически скачанного изображения, страница источника, название изображённого произведения, провайдер, дата доступа, доступные сведения об авторе и правах. Если автор или лицензия не установлены, поле остаётся `null` либо явно помечено как неизвестное. Наличие изображения в каталоге или Wikipedia не трактуется как свободная лицензия; полученные ограничения и подписи сохранены в `rights`.

Обложки подбирались по произведению и адаптации. Общая иллюстрация одной вселенной может обслуживать близкие общества, периоды и ветки концовок; список всех записей с тем же исходником находится в `shared_with`. Поля `illustration_scope` и `scope_note` раскрывают использование общей обложки, сборника, связанного тома или изображения вселенной. Обложка не используется как доказательство конкретной концовки или устройства экономики.

Во время просмотра заменены, среди прочего, сериал ReBoot 2022 года на анимационный ReBoot 1994 года, китайский игровой Shangri-La на аниме 2009 года и одноимённый роман Lazarus на комикс Грега Ракки. Убраны найденные внутренние страницы, рекламные заглушки и фотография игроков в Warhammer вместо обложки. История исправлений сохранена в манифесте, журнале, [review-corrections.json](review-corrections.json) и [скрипте заключительных исправлений](../../scripts/final_image_qa_corrections.py).

## Единственная генерация

Для редкого романа **Mr Jonnemacher’s Machine: The Port to Which We Drifted** (1898, Lord Prime / Walter Doty Reynolds) доступную подходящую обложку найти не удалось. Через встроенный OpenAI image_gen создана одна новая редакционная иллюстрация темы автоматизации и вытесненных работников. Она явно обозначена как сгенерированная, а не официальная обложка или канонический кадр.

[Сохранённый исходник](../../assets/images/img-mr-jonnemacher-s-machine-cead5791/original.png) · [Полный финальный промпт и параметры](generated/jonnemacher.json). Режим: новая генерация, непрозрачный фон. Для этого исключения `source_url` равен `null`, а `source_page` указывает на локальное описание генерации.

## Продолжение или замена отдельных изображений

Из корня проекта:

```powershell
python scripts/collect_images.py --validate
python scripts/collect_images.py --all
```

`--all` продолжает незавершённые группы, используя сохранённый поиск; уже подготовленные группы пропускаются. Сейчас продолжать нечего. Для правок отдельных изображений предусмотрены кандидаты `manual-candidates.json`, подготовка через `prepare_gap_files.py manual` и применение через `apply_image_candidates.py`. Сначала внесите конкретные выбранные источники; не запускайте заново разовые исследовательские скрипты массовых исправлений без необходимости. Смена изображения сбрасывает его отметку визуальной проверки. После замены пересоздайте контактные листы через `image_contact_sheets.py`, просмотрите изменённые изображения и сохраните результат проверки в манифесте. `collect_images.py --sync` переносит состояние манифеста в `assets` и журнал прогресса.

При обычной пересборке исследования достаточно `merge_batches.py`, `validate_data.py`, затем `collect_images.py --validate`. Не заменяйте `societies.json` исторической копией без последующего применения накладки изображений.
