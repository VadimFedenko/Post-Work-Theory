# После труда / After Work

Интерактивное приложение на React, TypeScript и Vite. Исходная база и исследовательские материалы сохранены без изменений.

## Локальный запуск

Нужен Node.js 22.12+ (рекомендуется 24).

```powershell
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Для проверки готовой сборки: `npm run build`, затем `npm run preview`.
Проверки данных и модели карты: `npm test`.

## Деплой GitHub → Vercel

Текущий снимок подготовлен к первой загрузке. Предлагаемое имя репозитория:
`VadimFedenko/after-work-atlas`, основная ветка — `main`. Видимость репозитория
может быть приватной: Vercel публикует собранный сайт отдельно от исходников.
По состоянию на 2026-10-23 удалённый репозиторий и деплой ещё не созданы.

1. Создать репозиторий GitHub и загрузить проект вместе с `data/`, `assets/images/`, `article.txt`, `src/`, `scripts/`, файлами конфигурации и `package-lock.json`.
2. В Vercel выбрать **Add New → Project → Import Git Repository** и нужный репозиторий.
3. Root Directory: корень проекта. Framework: **Vite**. Build Command: **npm run build**. Output Directory: **dist**. Node.js: **24.x**. Переменные окружения и серверная база для текущей версии не нужны.
4. Выполнить Deploy. Следующие изменения в подключённой ветке GitHub будут автоматически пересобирать сайт.

Настройки сборки также заданы в `vercel.json`. Сгенерированные `public/data/`, `public/assets/`, `dist/` и `node_modules/` исключены из Git; они воспроизводятся при сборке. Исходные изображения в `assets/images/` обязательно должны попасть в Git. Оригиналы изображений в веб-сборку не копируются — только используемые обложки и миниатюры.

GitHub Actions (`.github/workflows/ci.yml`) проверяет чистую установку зависимостей,
сборку и тесты на Node.js 24 при изменениях в `main` и в pull request.
Сборка выполняется перед тестами, чтобы подготовить производные веб-данные.

Для нынешней версии рекомендуемый вариант — GitHub + Vercel. GitHub Pages тоже
подходит для статического сайта, но при адресе `/<repository>/` потребуется
адаптировать абсолютные пути `/data/`, `/assets/` и конфигурацию Vite. Для Vercel
текущие пути уже подходят. Сервер, база данных и переменные окружения не нужны.

## Данные и поведение

- `scripts/prepare-web.mjs` создаёт компактный индекс, отдельный полный JSON каждой записи, реестр источников и копирует только файлы для отображения. Подробности загружаются по требованию.
- В индекс и полные записи включён `popularity_score` (0–1, шаг 0,05): редакторская узнаваемость именованного произведения/франшизы. Основание и группа — в `popularity_assessment`, отдельные ссылки — в `public/data/popularity-references.json`. Все 890 карточек оценены; [методика](research/popularity/methodology.md). Размер иконок определяется популярностью. У малоизвестных произведений маленькие цветные значки, у популярных — крупные миниатюры.
- Каждое общество отображается отдельно, ключ — `id`. В `scripts/atlas-layout.mjs` выталкивание рассчитывает визуальные координаты с сохранением исходных `anchorX` / `anchorY`. Группировки и счётчиков нет. При наведении название выбранного общества показывается над соседними иконками. Линии к исходным координатам не рисуются. Исходные записи не меняются. Подписи приоритетно получают популярные произведения; пересечения текста с кругами и другими подписями исключаются. Карту можно увеличивать и перетаскивать.
- Все фильтры можно отключить; остаётся цветная схема шести укладов. «Все» сбрасывает выбор отдельных форматов. Несколько форматов объединяются по ИЛИ. Поиск и фильтры общие для карты и таблицы.
- Фильтр «Посттрудовое общество» находится над картой и в таблице. Это ряд кнопок «Все общества / Посттрудовые / Трудовые / Переходные»; количество по каждому варианту видно в подсказке. Над картой форматы стоят слева, типы обществ в центре, информация и масштаб справа в одной строке. Легенда цвета, формы и размера также занимает одну строку. На узких экранах длинные группы прокручиваются горизонтально. Три категории берутся непосредственно из `post_work_assessment.status`: «Посттрудовое общество» (`post_work`, 470), «Переходное общество» (`transition`, 75), «Трудовое общество» (`zero_variant`, 345). В компактном индексе статус называется `post_work_status`; там же сохранён `wage_dependence`. Количества учитывают поиск и форматы до применения фильтра типа. Грубое `record_type` не подходит: оно объединяет посттрудовые и переходные общества.
- Посттрудовые иконки круглые; переходные и трудовые — правильные пятиугольники. Одинаковые маски используются на карте, в таблице и списке связанных обществ; контуры групп и PNG сохраняют форму. Цвет остаётся показателем утопичности. Название типа видно в карточке; раскрытие «Об устройстве экономики» объясняет зависимость от заработка и распределение благ. У 23 посттрудовых обществ с вытесненным трудовым доходом без надёжной замены показано пояснение «Без устойчивого обеспечения». Нулевые варианты могут быть безденежными общинами без достаточной автоматизации: название «Трудовое общество» не доказывает наличие зарплат.
- В таблице есть сортируемый столбец «Тип общества»; CSV дополнен полями `post_work_status`, `society_type` и `wage_dependence`. Общий фильтр типа применяется к карте, таблице и выгрузке. Открытие скрытого связанного общества на карте сбрасывает также этот фильтр.
- Цветной ободок соответствует `utopia_score`; белого внешнего контура нет. Цвет насыщается при −0,7 / +0,7. В карточках показаны текстовые уровни гарантий, контроля и утопичности. В таблице и CSV к ним добавлены условные баллы 0–100: гарантии `(1 − guarantees) × 50`, контроль `(control + 1) × 50`, утопичность `(utopia_score + 1) × 50`. Для контроля 0 означает автономный ИИ, 50 — элиты, 100 — общество. Доля работающих остаётся отдельным процентным показателем и не определяет размер.
- Поддерживаются исходная нумерация (адаптер `{0:0,1:1,2:3,3:2,4:4,5:5,6:6}`) и новая `taxonomy_version: article-2026-10-21` (номера уже совпадают со статьёй). Повторная перенумерация исключена. Нулевые варианты показываются с собственными координатами.
- Полный русский текст берётся из `article.txt`. Для английского эссе предусмотрена заглушка. Английские названия и описания из исследовательской базы не переводятся автоматически. Интерфейс двуязычный.
- При первом открытии включается тёмная тема. Язык — английский, а при русском основном языке браузера — русский. Выбор темы и языка сохраняется в браузере и имеет приоритет при следующем открытии.
- Фон карты одинаково светлый в обеих темах. Стыки шести зон медленно изгибаются; сетка, оси и координаты обществ остаются неподвижными. При системной настройке уменьшения анимации фон статичен. Анимация приостанавливает отрисовку в скрытой вкладке.

Изображения сопровождаются исходными метаданными происхождения и прав в полном раскрытии записи. Один компонент карточки используется на карте и во всплывающих окнах таблицы. На широком экране обложка занимает всю высоту карточки, а её ширина вычисляется по пропорциям изображения. Само окно расширяется, оставляя около 480 пикселей для текста; ограничения обложки в 220 пикселей или 30% ширины нет. Колонка совпадает с пропорциями обложки: изображение показывается целиком без кадрирования и пустых полос. Встроенные технические поля исключаются по `assets.crop.poster.content_box`. Когда окно слишком узкое для двух полноразмерных колонок, крупная обложка размещается рядом с шапкой, а описание — ниже на всю ширину. Всплывающее окно таблицы также расширяется по пропорциям обложки и остаётся в пределах видимой области. Исходные файлы изображений не меняются. Наведение открывает карточку, клик закрепляет её; Escape закрывает.

Шапка карточки компактная: формат и управление, название, тип общества и утопичность, отличающийся от названия контекст, затем контроль ИИ, гарантии и явно подписанная доля работающего населения. Повторяющий название `society` не выводится. Популярность из карточки убрана; она остаётся размером иконок и показателем таблицы. Название уклада размещено на обложке поверх градиента. Основное описание идёт сразу после шапки; связанные общества, устройство экономики и источники находятся ниже описания.

В светлой теме подписи обществ и укладов чёрные на белой подложке; в тёмной — светлые на тёмной. Скорость движения фона увеличена в пять раз относительно первоначального волнистого варианта; настройка уменьшения анимации по-прежнему отключает движение.

При наведении место обычной подписи остаётся занятым: она скрывается только после расчёта всех подписей. Поэтому соседние названия сохраняют позиции и не появляются заново из-за освобождения места или лимита подписей.

У каждого подсвеченного участника графа показана подпись `Society: …` / `Общество: …` из поля `society`. Обычные подписи произведений у этой группы временно скрыты с сохранением их зарезервированных мест. Длинные названия переносятся до трёх строк; полный текст есть в карточке и доступном имени подписи. Подписи предпочитают место под кругом, обходят другие подписи группы и остаются внутри поля; при смещении показана короткая линия к кругу. Эти подписи также сохраняются в PNG.

Связанные общества объединяются по сохранённому `popularity_assessment.subject_id` именованного произведения или серии. В компактный индекс передаётся `family` с ID и названием; совпадение изображений не используется. Это группа произведений/серии, а не утверждение о едином каноне всех версий или эпизодов. На карте подсвечены видимые участники группы, линии идут от выбранного общества к другим и не обозначают направление управления или исходные координаты. Карточка показывает группу и полный список её обществ, включая скрытые фильтрами. Выбор скрытого общества на карте сбрасывает фильтры; в таблице он открывает его карточку без изменения таблицы. Подсветка и линии включены в PNG текущего вида.

## Управление и сохранение карты

Кнопки информации, сохранения PNG и масштаба находятся справа от фильтров. Поиск остаётся в таблице; счётчик и переключатель названий убраны с панели карты. Подсказка об обозначениях открывается при наведении или фокусе на кнопке информации.

`src/atlas-export.ts` сохраняет текущий вид координат в PNG с осями, названиями и миниатюрами, без кнопок, карточек и боковой статьи. Экспорт берёт текущий кадр цветного фона и тот же шаг сетки, что интерфейс. Ожидание загрузки шрифтов и изображений ограничено. Файл сохраняется как `post-work-societies.png`.

`GRID_STEP` в `scripts/atlas-style.mjs` задаёт квадратную сетку 28 × 28 CSS-пикселей при масштабе 1×. Шесть цветовых зон имеют узкие переходы; зона 6 нейтрально-серая. Авторская подпись хранится в `src/Credits.tsx` и выводится внизу страницы и полного режима статьи.
