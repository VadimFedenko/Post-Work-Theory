The site serves its fonts locally. All fonts use the SIL Open Font License 1.1;
the corresponding license files are served from `public/fonts/`.

- **Manrope**: interface and headings, variable weight 400–800.
- **Golos Text**: article and long descriptions, variable weight 400–750.
- **Exo 2**: coordinate frame, variable weight 500–700, subset to the complete
  English and Russian alphabets, digits and coordinate punctuation. Font data is
  embedded in the SVG so the PNG export keeps the same typography.

WOFF2 subsets downloaded from the Google Fonts CSS API on 2026-10-30.
Sources: https://github.com/google/fonts/tree/main/ofl/manrope,
https://github.com/google/fonts/tree/main/ofl/golostext,
https://github.com/google/fonts/tree/main/ofl/exo2.
